## 项目经验

### 企业级智能客服Agent系统（2026年10月-11月）

**项目背景**：
针对中小企业客服成本高、重复性问题多的痛点，独立设计并实现了一个基于LangChain + RAG的智能客服Agent系统，支持知识库问答、多工具协作、自动路由。

**技术栈**：
LangChain、Dify、Claude API、Pinecone、Vue 3、Node.js、Express

**核心功能**：
1. **多工具Agent**：基于LangChain的ReAct框架，集成RAG检索、天气查询、转人工客服3个工具，Agent根据用户意图自动选择合适的工具
2. **RAG知识库**：支持PDF文档上传、文本切片（500字块+50字重叠）、向量化、语义检索
3. **多轮对话记忆**：保留最近5轮对话+历史总结，对话压缩降低成本40%
4. **流式输出**：SSE实现打字机效果，提升用户体验
5. **可视化配置**：Dify平台工作流构建

**技术亮点**：
1. **Agent自主推理**：用户问"上海天气怎么样？"→ Agent自动判断调用天气工具；问"请假流程？"→ 自动调用RAG检索
2. **双存储架构**：内存向量存储（必定成功）+ Pinecone（可选），Pinecone故障时自动降级到内存，可用性99%+
3. **完善的异常处理**：
   - 工具调用失败：自动重试3次（指数退避）
   - 超时处理：5秒超时→降级到纯LLM回答
   - 幻觉拦截：工具名校验+参数类型检查
   - 死循环检测：同一工具连续调用3次→中断
4. **RAG优化**：文本切片策略优化（根据文档类型动态调整chunk size），召回准确率85%+
